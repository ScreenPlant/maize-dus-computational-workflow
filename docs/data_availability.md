# Data availability

The repository provides Python analysis and inference scripts, analysis settings, trait definitions, empty data-manifest templates and software-version records. The historical C++ image-measurement application is not included.

| --- | --- |

| Later six-class checkpoint | Provided in `models/plant_later_6class.pt`; distinct from the study deployment model |

| Train/val/test manifest and biological grouping | [Pending verification] |
| Indoor trait-image collection | [Pending upload]; not included in this repository |

| Independent data-archive URL and DOI | [Pending upload] |

The image and annotation datasets are planned for a separate data archive, subject to data-holder authorization and protection of cultivar information. Verifiable archive links will be added after deposition. No archive or DOI is claimed here.

The current repository supports inspection and execution of the supplied code and models with appropriate local inputs. It does not yet support complete raw-image-to-trait or full study-level reproduction. No unauthorized images, cultivar identities or private data are included in this update.
