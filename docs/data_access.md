# Data access and reproducibility boundary

Cultivar-linked DUS phenotype records, identity correspondences, full imaging observations,
and the complete archived reference/evaluation membership are not included in this public
release, following the authors' stated confidentiality restrictions. Only approved representative
examples may be supplied publicly. Do not infer access permission from a filename or copied archive.

Exact reproduction of the reported 150-variety statistics requires the same protected inputs,
their order and the frozen 1,000 membership allocations. The public code documents the algorithm
but public examples do not reproduce those statistics or establish biological independence.
The Data Availability statement and reviewer response must describe this limitation explicitly.
No complete indoor dataset is claimed to have been publicly deposited. A DOI can identify
code and approved examples without exposing the full cultivar-linked records. No protected
files will be deposited, even with restricted access, without a separate author decision.
