# Approved examples only

This location is reserved for author-approved representative images and model annotations.
No cultivar-linked full dataset, complete phenotype table, or member-to-cultivar correspondence
is included. Original full input and resampling allocations are required for exact reproduction
of the reported study statistics and are not replaced by example images.

Whole-plant AI examples should include matched polygon annotations and class definitions.
Conventional indoor-organ examples do not require newly invented YOLO labels: retain the
scale/colour target and, where authorized, the corresponding output or ROI information.
An example set does not constitute a new independent test set.
