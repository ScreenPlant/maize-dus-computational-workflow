# Version 2.0.0

The default workflow now implements reliability screening before exhaustive constrained
selection, 10,000 all-subset confirmation simulations, an independent 10,000-simulation
selected-subset audit, and 1,000 complete 120/30 nested reselections. Gates, calibration,
ranking, failures and counting units follow the revised protocol. The prior default
five/six-trait configurations, weighted-score entry points, 100-split scripts and kernel-AI
instructions are removed from this release tree. Earlier commits remain traceable in Git history.

Protected full inputs are not included. C++ measurement source is outside the release scope.
No claim is made that a public example set permits exact reproduction of all study statistics.
